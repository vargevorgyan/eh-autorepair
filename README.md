# E.H. Auto Repair

Static HTML/CSS/JS site for [eh-autorepair.com](https://eh-autorepair.com), converted from the Next.js app for GitHub Pages.

## Stack

- HTML, CSS, JavaScript (no build step)
- Hosted on GitHub Pages from `main` branch root

## Local preview

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Custom domain

`CNAME` is set to `eh-autorepair.com`.

## QR code

`assets/eh-autorepair-qr.png` — links directly to `https://eh-autorepair.com` with logo in the center.
